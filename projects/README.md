# 小项目与实验

## 项目列表

- [知行办](zhixingban/README.md)：Windows 优先的本地个人任务管理工具，六个页面共享任务数据，支持离线运行和 JSON 备份恢复。
- [灵感镇 · AI Town](ai-town/README.md)：可交互的小镇实验，支持事件、资源、居民记忆与可选 AI 对话。

## 新建实验

每个实验放在独立目录里，例如 `projects/tiny-game/` 或 `projects/sorting-demo/`。按项目需要选择语言、框架和依赖。

每个项目附一份 README，写清楚：

- **目的**：想实现什么，验证什么。
- **运行**：所需环境、依赖安装和启动命令。
- **验证**：实际执行的检查及结果，未验证的部分单独注明。
- **记录**：已知局限、遇到的问题和下一步想法。

半成品和失败实验也可以保留，注明当前状态即可。不要把密钥、私人数据或依赖安装目录提交到仓库。
